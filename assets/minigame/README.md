# 小游戏美术工作区

本目录是「真夜中道路」的美术源与验收工作区，不是可直接打包的运行时目录。

| 目录 | 职责 |
| --- | --- |
| `cars/` | 车辆锚点和后续逐车交付 |
| `layers/` | 720×1280 赛道图层栈与机器表 |
| `palette/` | 锁定色板及生成源 |
| `previews/` | 构图/透视验证图和辅助脚本 |
| `refs/` | 风格与构图参考，不进包 |

总规范读 `../../docs/art-bible.md`、`../../docs/art-bible-revision-01.md` 和 `../../docs/art/`。Gate 6 已解除，仍不得把预览图或签名稿当成已批准资产导入 Cocos。
