# 宝开语图鉴

只写图鉴正文。机制以契约为准，文案不得改碰撞、得分、解锁。

## 先读

1. [CONTEXT.md](../../../../CONTEXT.md)
2. 车的硬规则：[docs/car-almanac-brief.md](../../../../docs/car-almanac-brief.md)
3. 已通过的车图鉴：[docs/ui-copy.md](../../../../docs/ui-copy.md)
4. 结构与禁令：[references/style.md](references/style.md)

有新条目就按 style 写，交到 `docs/ui-copy.md`（车）或日后图鉴目录。不要另起称号覆盖已通过的：逮虾户、钢板、无头骑士、云玩家、DIO。

## 结构（必须三段）

1. **称号**：`【中文名】（英文意译）`。好听好记，像小小车、轰鸣者。禁止薄壳、编内、虚线户、楼上、计价员。
2. **一句格言**：20 字内，哲理或反差。单独加粗一行。
3. **正文**：150–250 字。把命格、速度、技能、钻缝、飞行不计技巧分、第一版无续命，写成生活烦恼，不写「玩家可以」。
4. **独白**：独立成段，斜体。格式：`「……，」称号一边[动作]一边说/嘀咕/冷笑，「……。」`

少用「它」，用称号称呼。前半句要强，后半句必须反转。

## 硬规则怎么藏

| 机制 | 写成 |
| --- | --- |
| 命格厚/薄 | 出门叠满、苏打饼干、玻璃心。不说血量 |
| 技能 / 条 | 个人信仰或任性，不是 CD |
| 钻缝 / 体积 | 跳芭蕾、走钢丝、和邻居亲吻、挤进不属于它的缝 |
| 飞只计路程 | 高处不胜寒、地面技术庸俗、没人鼓掌 |
| 第一版无续命 | 字典里没有续命、烟火的一生 |
| 晚躲才擦车 | 对安全距离过敏、最后一皮秒才移开屁股 |
| 碾 +500 | 提款机、就地回收、满条双击时停清屏 |
| 停虚线会撞（非摩托） | 车漆经不起邻车道亲吻 |

## 不做

- 不改 `GameBalance`、碰撞、分值
- 不写新手教程句（「本车特点是」「玩家可以使用」）
- 不用过期烂梗（奥利给、绝绝子）
- 不给已通过的五车强行换称号，除非 Hans 点名

## 交付

每条交：称号、格言、正文、独白。车条附上简报里的四行性能（速度 / 命格 / 技能 / 钻缝），性能行用人话，不要倍率。
