## 3. 需求澄清（试玩后已锁）

这些不要在界面优化里推翻。词在 `CONTEXT.md`，决定在 ADR。

| 题 | 结论 | 出处 |
| --- | --- | --- |
| 横移 | 跟手拖，松手停缝，点一下不挪 | ADR 0003 |
| 加速 | 双击；氮/飞可按住；压路机必须满条双击一次 | ADR 0003、0009 |
| 擦车 | 贴近车辆后横移完成危险通过；含迎面晚躲和同向贴近超车 | ADR 0011 |
| 连击 | 只吃擦车，200/300/400/500 | ADR 0005 |
| 命格 | 保险杠格 + 1 心，HUD 画成一排 | ADR 0008 |
| 重量 | 更重撞飞不扣格；一样或更轻扣一格 | ADR 0008 |
| 钻缝 | 只有摩托停虚线能过；别的车挂虚线会撞 | Gate 3 |
| 选车说明 | 只要速度/命格。技能和钻缝让玩家自己发现 | Hans 当场否说明书 |
| 图鉴 | 用 `ui-copy.md` 宝开语，不要自拟介绍 | Hans |
| 第一版广告 | 无。续命页不出现 | ADR 0006 |
| 屏幕 | 落地是发车。选车确认回发车。只有发车「开车」上路 | ADR 0007 |
| 施工 vs 路形 | **同一段不叠**。施工=三车道宽+堵一条；路形=大桥/隧道/土路把路收窄 | ADR 0010 |
| 机位 | 试玩修订 A-2，消失点 (376, 700)，`k=1.572` | RoadProject + 本文；修订 01 保留历史依据 |
| 画布 | 720×1280。菜单可 CRT，局内平直 | CONTEXT |

开车 HUD 约定：顶栏左=命格+四段技能条，中=总分与 `×N`；右上角空给微信胶囊。底部中央半圆环仪表=时速与累计计时（色块整圆只占位）。技巧分跳字并燃烧，路程匀发不烧。这不是倒计时。

### 选车图鉴结构（已定稿，不要改意思）

每辆：`称号` + 英文小名 + **一句格言** + 正文 + 独白。通篇少用「它」，用称号。

| id | 称号 | 英文 | 速度行 | 命格 |
| --- | --- | --- | --- | --- |
| sports | 逮虾户 | Déjà vu | 基准 | 2 |
| truck | 钢板 | The Steel-Plate | 更慢 | 4 |
| moto | 无头骑士 | Headless-Rider | 比跑车快，比飞行汽车慢 | 1 |
| flyer | 云玩家 | Cloud-Pilot | 最快 | 2 |
| roller | DIO | The Flattening | 最慢 | 4 |

### 说明页只有三句（有意写短）

```
拖：车跟着走，松手停在那儿。点一下不挪。
双击松开是短冲，第二下按住会持续。
贴近车辆再横移通过，才算擦车。
```

不要补技能、钻缝、重量、施工教程。

### 结算一行

标题 ∈ 抵达 / 肇事 / 翻车 / 逮捕。正文只一行，见表 [ui-copy.md](ui-copy.md)。施工撞墙目前用翻车：「施工围挡比你更硬。」（`RunSession.WORKS_FAIL`，尚未写入 ui-copy。）

完赛一行：「天亮了，昨晚是平安夜。」

### 界面固定短词

开车、选车、说明、确定、返回、再来、回发车、分数、好友榜。失败演出大字用标题本身（肇事/翻车/逮捕）。

HUD 跳字：`擦车 +N`、`碾压 +N`、`挨打`、`撞飞`。时停/粉碎是压路机状态，不是按钮。

HUD 路况字（色块预览用，出图后可收）：`晴/雨/雪/雾/风 · 城/港/厂/桥/河`，进入特殊段改成 `施工/隧道/大桥/土路`。

6. 远景带位置试过几轮，仍要以消失点那条水平带为准，不要盖住路和中景。
7. `NitroBtn` 节点还在，已隐藏；加速只有双击。
8. HUD「晴 · 施工」是预览路况，出图后不一定留。
