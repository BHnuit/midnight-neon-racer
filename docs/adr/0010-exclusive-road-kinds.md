# 施工路障和路形变化不同时出现

**Status**: accepted
**Date**: 2026-08-18

## Context

路段可以限制横向空间。曾试过同一段既堵墙又把路收窄。Hans 否定：那是两套机制，不能叠在同一段上。

## Decision

拆成互斥的两种路段。

- **施工路障**（`works`）：仍是三车道宽的城市路。堵住左边或右边一条，围挡和锥桶标在那条道上。撞围挡是翻车。
- **路形变化**（`form`）：大桥、隧道或乡村土路。路面跟着收，两侧是桥栏、岩壁或土路肩。不摆施工锥。

第一段永远是开阔三车道。同一段不能同时带 `works` 和 `form`。

## Consequences

- 种子只给每段一种 `kind`。
- 施工段的可视路宽保持三车道；路形段才改 `roadLeft` / `roadRight`。
- 预览色块也必须分得清：锥桶只出现在施工段。
