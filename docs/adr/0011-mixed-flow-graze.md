# 混合车流共用擦车连击

**Status**: accepted
**Date**: 2026-08-18
**Partially supersedes**: [ADR 0004](0004-late-dodge-graze.md) 中“只有迎面晚躲算擦车”的范围限制

## Context

车流已改为同向巡航与迎面危险段混合。玩家对两类交通做的是同一个动作：贴近目标，在碰撞前横移并从旁安全通过。若给同向超车另造一套名称、分数和连击，输入相同但规则分裂；若普通远距离超车也给分，又会退回“邻道白给”。

## Decision

“擦车”统一指没有碰撞地贴近一辆交通车并完成一次危险通过。迎面车仍按 ADR 0004 的晚躲条件判定；同向车必须由后追上，在近距包络内从车旁越到前方，普通提前换到远车道的超车不算。两种擦车进入同一条 200 / 300 / 400 / 500 连击，同一交通 id 整局最多结算一次，飞行和碾压期间仍不计擦车。

## Consequences

- 玩家界面、结算和文案继续只使用“擦车”，不增加“险过分”或“超车分”第五项。
- core 应使用统一的近失事件并携带 `oncomingLateDodge` / `sameDirectionOvertake` 子类型；表现层不靠相对方向猜事件。
- 同向车只有完成“后方→近距并行→前方”的一次通过才触发，停在旁边磨蹭、反复横跳或同一辆车二次落后再追上都不能刷分。
- ADR 0004 继续定义迎面子类型的晚躲条件，不再排除同向贴近超车。
