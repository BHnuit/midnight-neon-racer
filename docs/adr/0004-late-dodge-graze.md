# 擦车是迎面晚躲，不是贴身路过

**Status**: accepted
**Date**: 2026-08-18

## Context

邻道白给 +200 在试玩里没有技巧感。横向贴身计分也不对：Hans 要的是「脸上这辆车马上要撞上，最后一刻让开」。跟手横移之后没有离散「变道」，只能用碰撞线判定。连击已定为进第一版，加成算法另锁。

## Decision

一辆车先处在碰撞线上（不让开会撞），并已经逼近到危险窗内；人车在这一刻横移离开碰撞线，越过该车才记一次擦车。早早让开、从未对上过、只是从旁边开过，都不算。飞行期间仍不计擦车。同一目标不能既擦又碾。危险窗的具体时长留给试玩，不锁死数字。

## Consequences

- 判定看「会不会撞」和「何时离开」，不看两车横向有多近。
- 不能靠提前变线或钻缝挂机刷擦车。
- 摩托更窄，离开碰撞线需要的横移更短，晚躲窗口更好用。
