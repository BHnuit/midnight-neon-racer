# 第一版做擦车连击，只吃擦车

**Status**: accepted
**Date**: 2026-08-18
**Supersedes**: 方案与 `CONTEXT.md` 里原先的「第一版不做连击」

## Context

晚躲擦车若每下都是固定 +200，仍偏弱。Hans 要在擦车成功后的短窗口里再擦上，形成连击加成。备选是第一版只做单次晚躲。碾压、路程、完赛不进连击。

## Decision

第一版做连击。只由擦车续上；窗口结束或撞车断开。加成用阶梯加分并单笔封顶，不乘整局总分，也不另开第五项。初值：第 1 下 +200，第 2 下 +300，第 3 下 +400，第 4 下起每下 +500。窗口秒数试玩再定。

## Consequences

- 结算必须能拆出擦车基础和连击加成，不能只给一个技巧总分。
- 车流间距大约 1–3 秒一辆，窗口长短会决定「正常开就能连」还是「要赶着躲」。
- `docs/plan.md` 里「第一版不做连击」作废。
