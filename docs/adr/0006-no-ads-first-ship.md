# 第一版无广告、无续命

**Status**: accepted
**Date**: 2026-08-18

## Context

Hans 提供正式 AppID `wxcce206285c95068b`。流量主开不了：个人号累计 UV 不足 500，也没有游戏圈活跃或同主体已变现的小程序。他决定第一版先做无广告。继续等广告位会卡住上架。

## Decision

第一版不接激励广告，心归零直接结算，不出现续命页。上架路径仍是个人主体、声明不开虚拟支付。续命代码保留，`offerRevive` 默认关。流量主开通并有激励广告位后再打开，走 Gate 4 真机看一次。

## Consequences

- 不能宣称 AC-iaa 的广告部分通过。
- 备案玩法不要写「看广告续命」。
- AppID 可写入构建配置；广告位 ID、上传私钥、AppSecret 不得入仓。
