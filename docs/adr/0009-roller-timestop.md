# 压路机改为满条双击、时停清屏

**Status**: accepted
**Date**: 2026-08-18
**Supersedes**: 压路机按住一段碾车，与飞行汽车同一套手势

## Context

按住碾和按住飞都是「这段时间路面车不当回事」，碾还多给 +500。Hans 要拆开：压路机学 DIO / 幽灵行者，极慢变成时停，一次清屏。

## Decision

压路机技能条必须满才能放。双击一次：时间暂停，碾碎当前屏幕上所有来车，每辆 +500，然后恢复正常驾驶。不能按住一段段放。氮和飞仍是双击短冲 / 按住持续。无头骑士地面最快。

## Consequences

- 压路机开局半表时放不出技能，要先捡装置或靠别的补满。
- 清屏范围是「当前屏上可见来车」，不是整张大图。
- 图鉴 DIO 按住不放的句子作废。
- `RunSession` 的 crushing+hold 要换成一次结算。
