# 人车横向连续，松手停在线缝上

**Status**: accepted
**Date**: 2026-08-18
**Supersedes**: `CONTEXT.md` 里原先的「滑动换道 / 人车只能停格心」

## Context

Gate 2 试玩后，Hans 否定离散换道：车不跟手，摩托无法停在两车夹缝里，擦车也只能是邻道白给。三车道作为路和车流结构仍然成立；要改的是人车横向模型。备选是松手吸回最近车道，或只做换道插值、底下仍三格。

## Decision

人车跟手横移，松手停在松开处，不吸回格心。点一下不挪车，拖了才动。路和车流仍按左中右三道排。加速改为双击（短冲）/ 双击按住（持续），去掉右下角独立按钮；加速时仍可横移。擦车见 [ADR 0004](0004-late-dodge-graze.md)，不得再按「邻道即擦车」实现。

## Consequences

- `RunSession` 不能再用车道整数当人车位置；碰撞按车身是否重叠算。
- 路窄段限制的是活动宽度，不是把人弹回仅剩的那条道。
- 只有摩托能停在虚线上穿过邻道车流；跑车及更宽的车停在缝上会撞。
- 备案/介绍里不要再写「换道前行」。
