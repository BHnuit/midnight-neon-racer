# 保险杠和重量级一起用

**Status**: accepted
**Date**: 2026-08-18

## Context

Hans 要来车分大小：更重的能撞飞更轻的、不扣心。同时问还要不要保险杠。只留重量级会废掉货车/压路机的多格命；只留保险杠没有「中型撞飞小型」。

## Decision

两套一起用。重量级（摩托 < 小型 < 中型 < 大型）决定这一下疼不疼：你更重则来车飞走、不扣格；一样或你更轻则扣一格。保险杠仍是能挨的格数（跑车/飞车 1 杠+1 心，货车/压路 3+1，摩托 0+1）。摩托最轻且一格，碰谁都死。飞行期间仍无视。无头骑士地面最快；云玩家落地不必抢时速。

特效：中途还活着则来车飞出屏。最后一下按标题演：肇事停下闪烁，翻车翻滚，逮捕停下并闪红蓝警灯。

## Consequences

- 来车必须带重量级，不能再是一种匿名色块。
- 选车图鉴可写「钢板撞小的不痛」，不能写「没有保险杠」。
- `RunSession` 碰撞要先比重量再扣格。
