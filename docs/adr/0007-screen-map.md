# 第一版屏幕：发车进门，结算出两 tab

**Status**: accepted
**Date**: 2026-08-18

## Context

出图前要定 UI 块。实现里打开就是选车，没有发车页和说明页。CRT 契约已把发车和选车分成两块皮。第一版无续命。Hans 指定：发车页中间开车、右下选车和说明；局后结算可切分数/排行；结算后回发车或再来。

## Decision

落地是发车页。「开车」用当前已选车开局（新号跑车），页上要露出这辆车。选车、说明从发车页进入，不挡开局。选车确认后回发车，不能从选车页上路。结算两个 tab：分数统计、好友榜。再来＝同车立刻再开；另一出口回发车页。续命页第一版不出，也不出图。

## Consequences

- 出图按发车 / 选车 / 说明 / 开车 HUD / 结算（两 tab）五套，不加续命。
- 选车是左右翻页：侧视、速度/命格、宝开语；确认回发车。技能和钻缝不写进说明或性能表。文案在 `docs/ui-copy.md`。
- 菜单槽位按 720×1280 钉死：标题 / 车图 / 格言 / 性能 / 正文 / 主按钮 / 右下导航。出图只换槽里的图和字，不重排。
- 开车 HUD 在顶：左=命格+其下技能条，中=总分，右=时速+其下本局累计计时。技巧分跳字并做加分燃烧，路程匀发不烧。不是倒计时。
- 结算失败标题/一句提示跟撞上的来车走；警车为逮捕。文案在 `docs/ui-copy.md`。
- 实现要把选车从落地页拆开。
- 选车确认后回发车；只有发车页「开车」开局。
