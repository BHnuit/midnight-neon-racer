# 第一版屏幕：发车进门，结算出两 tab

**Status**: accepted
**Date**: 2026-08-18

## Context

出图前要定 UI 块。实现里打开就是选车，没有发车页和说明页。CRT 契约已把发车和选车分成两块皮。第一版无续命。Hans 最初指定发车页中间开车、右下选车和说明；2026-08-19 试玩后把当前文案调整为「发动」「车库」，并要求标题为第一视觉层、车辆窗缩小下移。局后结算可切分数/排行；结算后回发车或再来。

## Decision

落地是发车页。「发动」用当前已选车开局（新号跑车），页上要露出这辆车；「车库」、说明从发车页进入，不挡开局。选车确认后回发车，不能从选车页上路。标题是第一视觉层，车辆只作当前选择确认。结算两个 tab：分数统计、好友榜。再来＝同车立刻再开；另一出口回发车页。续命页第一版不出，也不出图。

## Consequences

- 出图按发车 / 选车 / 说明 / 开车 HUD / 结算（两 tab）五套，不加续命。
- 选车是左右翻页：侧视、速度/命格、宝开语；确认回发车。技能和钻缝不写进说明或性能表。文案在 `docs/ui-copy.md`。
- 菜单槽位按 720×1280 钉死：标题 / 车图 / 格言 / 性能 / 正文 / 主按钮 / 底部导航。出图只换槽里的图和字，不重排。最终尺寸见 `docs/ui-art-production-spec.md`。
- 开车 HUD（[ADR 0012](0012-bottom-hud-cluster.md)）：顶栏左=命格+技能条、中=总分与 `×N`；底部半圆环仪表=时速与累计计时（色块整圆只占位）。技巧分跳字并做加分燃烧，路程匀发不烧。不是倒计时。右上角不放数字，避开微信胶囊。
- 结算失败标题/一句提示跟撞上的来车走；警车为逮捕。文案在 `docs/ui-copy.md`。
- 实现要把选车从落地页拆开。
- 选车确认后回发车；只有发车页「发动」开局。
