# 局内 HUD：顶栏状态 + 底部时速环

**Status**: accepted
**Date**: 2026-08-19

## Context

微信小游戏右上角胶囊会盖住原先顶栏右侧的时速和计时。把整套 HUD 都堆到底部后，本车附近数字乱跳，读起来更花。需要拆开：状态和加分仍在顶，驾驶读数单独成一只仪表。

## Decision

- 顶栏只留两块：左=命格+四段技能条，中=总分与纯 `×N`。右上角空给胶囊。
- 底部中央单独一只仪表：正式形是半圆环仪表盘；环内大数字是时速，环内小数字是累计计时；环的填充表示相对最高显示时速。氮/飞/碾时环改品红。
- 色块原型里的整圆 Graphics 只占槽位，Gate 6 出图时整件替换，不再打磨这只占位环。
- 不加整条底栏，不把跳字和发车灯塞进仪表。

## Consequences

- [CONTEXT.md](../../CONTEXT.md)、[ADR 0007](0007-screen-map.md)、[ui-art-production-spec.md](../ui-art-production-spec.md) §6.1 按此分槽。
- 出图时顶栏两块底板与底部半圆环仪表是两套件，不是三块同高顶栏。
