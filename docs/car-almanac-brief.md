# 选车图鉴 · 机制简报（给文案 agent）

只写规则。不要沿用任何已废称号。车名只用下面五个正式名。

## 你要交什么

选车页左右翻，一次一辆。每辆需要：

1. 一句短铭言
2. 一小段正文（性格 / 场面 / 机制藏在笑话里）
3. 一句带动作的对白（「……，」某某一边……，「……。」）
4. 一个称号（中文为主，可附英文小名）。要好听、好记，像「小小车」「轰鸣者」，不要「薄壳 / 编内 / 虚线户 / 楼上 / 计价员」

风格：宝开图鉴。把车写成有性格、有烦恼的人。用最严肃的语气讲最荒谬的笑话。前半段听起来很强，后半段露出无能、无奈或尴尬。**通篇少用「它」，用称号称呼。** 机制必须对，但不能写成说明书。

## 全车共用（写任何一辆都要守）

- 竖屏夜驾。拖着走，松手停在松开处。点一下不挪车。
- 双击：氮/飞是短冲，按住持续到条尽。压路机必须满条，双击一次放完（时停清屏），不能按住一段段放。没有右下角按钮。
- 擦车：必须本来会撞、已经逼到脸上，最后一刻让开才给分。早早让开不算。邻道路过不算。
- 连击：擦车后短时间内再擦上，+200 / +300 / +400 / 此后每下 +500。只吃擦车。
- 碾压：压路机满条双击一次，时停并碾碎当前屏上所有来车，每辆 +500。同一辆不能既擦又碾。
- 飞行期间：只加路程，不擦不碾，无视车流。
- 命格 = 保险杠格 + 1 心。HUD 画成一排格。空了再撞就结算。第一版无广告续命。
- 重量级：摩托 < 小型 < 中型 < 大型。你更重：来车飞走、不扣格。一样或你更轻：扣一格。摩托碰谁都死。
- 钻缝：只有摩托停在车道虚线上，邻道来车撞不上。其他车停在虚线上会被邻道车撞。
- 解锁（文案可提可藏）：新号跑车；约 2 局货车、6 局摩托、15 局飞行汽车和压路机。

## 选车页还要展示的性能行（用人话，不要倍率）

选车页性能只显示两行：速度 / 命格。技能和钻缝留给玩家自己发现，不要写成说明书。

## 不要写

- 说明书腔、参数表腔
- 已否掉的称号
- 摇杆、方向盘、圈、全球榜、广告续命
- 把钻缝写成所有车都能做
- 把飞写成永久离地
- 把货车写成能碾
