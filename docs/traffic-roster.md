# 来车图鉴 · 种类与机制

路面车不再是一种色块。每种有重量、接近速度、占道、行为和出现权重。种子决定种类和车道，必须可复现。

重量：摩托 < 小型 < 中型 < 大型（与 [ADR 0008](adr/0008-weight-and-bumper.md) 相同）。

**接近**：当前实现里来车钉在大图距离上。要做快慢，来车必须在世界里自己走。慢车在危险窗里待得久，好擦也好撞；快车一闪而过。

**占道**：1 = 一条道；2 = 同时占相邻两道（缝被吃掉）。

**权重**：每出现一辆来车时抽签。总和 100。主题可再偏置（见文末）。

**第一版只上 ★ 的 10 种**（Hans 2026-08-18 同意）。其余 14 种进图鉴池，随后按主题加。结算失败提示跟撞上的那一辆走。

## 特殊规则（写进规则，不要只当皮肤）

**电瓶车穿行**：每隔约 400–700 世界距换到一条邻道（种子决定节奏）。换道中仍可擦、可撞。货车撞上仍飞、不扣格。

**老头乐**：接近极慢，等于在车道里摆了一块会动的石头。压路机清屏很赚。

**豪华大巴 / 公交**：占两道。被占的两道之间不能当摩托缝。跑车贴边等于贴车身。

**警车**：在它的碰撞线上进入危险窗再离开 = 逮捕，进结算，不算擦车、不加连击。早早让开没事。飞过去、碾过去仍按飞/碾规则（碾 +500，飞只路程）。

**油罐**：重量按「比大型还不可撞飞」处理：只有压路机技能能清掉。钢板撞它扣格。

**救护车**：鼓励早让。+50 是小费，不算擦车、不进连击。

## 图鉴

以后每种来车一篇宝开语，撞过或碾过才解锁条目。第一版不必做图鉴页，种类数据要按上表预留 `kind`。

## 不要

- 写实爆炸、碎尸（12+）
- 来车真转向、对向会车物理
- 警车变成强制游戏结束且分作废
- 电瓶车无规律乱跳（必须种子可复现）
