# 路边推近

楼离路边远，是静态落位问题。开起来两侧要往镜头里「长出来」，是运动问题。两件事分开做，素材也分开交。

已锁机位（修法 A）：消失点 `(376, 797)`，半路宽斜率 `k = 2.244`，路肩 `d = 30`（允许 30–120，左右同值）。公式见 [修订 01](../art-bible-revision-01.md) §4。

不要把整座城画成一张透视好的静帧底板再往前开——那张图只有一个正确的 z，一动就穿帮。

## 1. 静态：楼必须坐在底边上

城市底边（楼脚碰到地面的那条线）：

```
y_底边(x) = 797 + max(|x − 376| − d, 0) / 2.244
```

| x | 30 | 90 | 150 | 210 | 270 | 330 | 376 | 690 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| y_底边 | 938 | 911 | 884 | 858 | 831 | 804 | 797 | 924 |

生成 `02-mid` / `01-far` 时，楼脚必须落在这条线上 ±15px。楼顶可以伸出画框。不要为了露楼顶把底边抬回去。

路沿到楼脚之间只许有宽 `d` 的路肩（点阵 + 一条平行路缘石）。现在预览里 110–242px 的碎石暗带，下一套中景必须吃掉。

`01-far` 是剪影，贴在底边更靠消失点的一侧，几乎不动。`02-mid` 才是会推近的那一层。

## 2. 运动：沿射线、按 1/z 放大

玩家往前开，世界坐标 `z` 增大。屏幕行和深度的关系用现成扫线，不要另开一套相机：

```
z(y) = 1 / (y − 797)          # y > 797
scale(y) ∝ (y − 797)
```

路边任何东西的脚点必须在「路沿往外 `d`」的那条射线上。东西近了，不是往画面中间挤，而是：

1. 脚点沿射线往画面下方、往左右外边走
2. 整栋楼按 `scale` 变大
3. 大到脚点出画或高度超过近景预算，就消失，下一块接上

远、中、近三层速度不一样（视差）：`01-far` 的 z 变化最慢，`03-near` 最快。路灯、护栏柱按 `03` 的 z 走，楼按 `02` 的 z 走。

## 3. 素材做成两种，不要一种打天下

你猜的「纵向长图」对，但只负责**密的那一层墙**。能认出来的房子、店、灯，另做成卡片。

### 3.1 街墙长图（密、可拼、可滚）

给图像 agent 的交件：

| 项 | 值 |
| --- | --- |
| 文件 | `layers/02-mid/<主题>-wall.png` |
| 尺寸 | **128×2048**（宽 = 进深，高 = 路程） |
| 格 | `p = 2`，硬边 |
| 色 | 游戏01 + 底/暮底，禁止新色相、禁止汉字 |
| 纵向 | 每 **256px** 一块地块，8 块接成一条；地块顶底可无缝或留 2px 暗缝 |
| 横向 | **x=0 靠路**（门脸、一楼橱窗），**x=127 往城里面**（墙面淡进夜靛，交给 `01-far`） |
| 左右 | 只画「路左侧」一条，右侧运行时镜像；不要交一张已经透视变形的图 |

种子拼大图时，按地块 ID 抽 8 块竖着接，不要抽一整张 2048 再裁。同一主题至少准备 12 块不同地块，避免一眼看出循环。

运行时（扫线采样，伪代码）：

```
for y in (798 .. 1279):
    x_in  = road_edge(y)          # 路沿
    x_out = city_baseline_x(y)    # 底边反解，或夹到屏边
    v = (z_cam + 1/(y-797)) * V_SCALE
    for x in (x_in .. x_out):
        u = (x - x_in) / (x_out - x_in)
        color = wall[u * 128, v % 2048]
```

`V_SCALE` 调到：一块 256px 地块从刚能看清到出画，大约 1.2–1.8 秒满速。长图**不要**预烤成梯形，梯形由这层采样产生。

### 3.2 路边卡片（疏、能认、能推近）

给图像 agent 的交件：

| 项 | 值 |
| --- | --- |
| 文件 | `layers/02-mid/<主题>-card-<id>.png` 透明底 |
| 设计尺寸 | **80×128** 或 **64×96** |
| 锚点 | 底边中心 = 落在射线上的脚点 |
| 内容 | 一栋能认的东西：便利店块、灯塔、水塔、牌坊、广告塔（几何块，不写字） |
| 缩放 | 上屏用最近邻；远 16px 高仍要认得剪影 |

世界里每张卡片只有 `(side, z)`。不要给卡片画地平线或路面。

路灯、护栏立柱走 `03-near`，规格相同，只是更瘦、更密、z 间隔更短。

## 4. 图像 agent 一次交什么

按**一个路段主题**交一套，不要交一张「已经摆好透视的街道完成图」。

1. `01-far/<主题>.png`：只含远剪影，楼脚齐 `y_底边`，天空透明
2. `02-mid/<主题>-wall.png`：128×2048 长图
3. `02-mid/<主题>-card-01.png` … 至少 4 张
4. `03-near/<主题>-prop-*.png`：灯、柱、栏
5. `manifest.md`：主题名、地块数、卡片锚点、未修好的缺陷

禁止：把车、数字、氮光带、CRT 签名画进这些层。禁止交已经桶形畸变的图。

## 5. 预览怎么验收「推近」

静帧至少交三张同一套墙+卡片、只改 `z_cam` 的图：

| 帧 | 看起来 |
| --- | --- |
| 远 | 楼在底边上，小，贴着消失点两侧 |
| 中 | 同一栋明显变大，脚点下移外移，还在射线上 |
| 近 | 大到快出左右画框，下一栋已经在后面冒出来 |

抽 5 条与路平行的线（墙脚、灯座连线、长图里的檐线），延长必须过 `(376, 797)` ±20px。
