# 空天件

连续无内容的天空不得超过画高 **25%**（720×1280 上 ≤ 320px）。现在预览约 545px，差一块「空天件」。

空天件只放 `00-sky`（天色底 + 主件）和偶尔 `01-far` 伸出的尖。天气粒子仍在 `07-fx`，不要把雨雪画进天空层。

## 怎么拼

天空 = **天色底** × **路段主件**。一局天色从傍晚转到清晨（横带往上抬、变亮）；主件由种子按路段抽，整段不换。

| 天色 | 底怎么画 |
| --- | --- |
| 傍晚 | 下半橙粉横带（ref-5），上半夜靛 |
| 夜里 | 靛到墨，可加疏星点阵 |
| 清晨 | 横带抬高变浅，楼剪影相对更暗 |

主件规则：

- 只有 **1 个主件** 占空（月亮 / 落日 / 灯牌阵 选一个最大的），可加 **0–2 个小件**
- 坐在 y=120–520 这段，不要挡消失点附近的路尖
- 色只用色卡；几何块，**不写汉字、不写商标**
- `p=2`，远景点阵 1px
- 主件可以很大，但不能做成第二套透视地面

## 路段主件目录

给图像 agent 按主题名取一行，不要自己发明色相。

| 路段主题 | 主件 | 小件 | 别做成 |
| --- | --- | --- | --- |
| 城区 | 2–4 块悬浮灯牌（品红/青矩形 + 电蓝支架），一大三小 | 探照灯两道扫空（青，虚线点阵） | 真广告字、CRT 窗 |
| 港湾 | 大月亮（`play-night.jpg` 那颗量级，y 250–320） | 水面反光只到远剪影，不画进路 | 棕榈度假 |
| 旷野 | **巨月**，直径 180–260px，偏一侧 | 远山剪影属 `01-far`；一颗流星 | 写实月球照片 |
| 山脉 | 月从山肩升起，月被脊挡住 1/4 | 琥珀山棱扫光一条 | 白天青山 |
| 村庄 | 烟花：3–5 簇放射点阵，品红+琥珀 | 两三盏纸灯笼色块（无字） | 写实爆竹、人脸 |
| 神社/高架 | 一排几何鸟居剪影伸进 `01-far` | 一盏大灯笼色块 | 神道教符文、汉字匾 |
| 工业 | 两根烟囱剪影 + 顶上警示闪点 | 远处理货塔红点 | 浓烟写实、污染说教 |
| 港口 | 灯塔扫光（琥珀扇形点阵，很稀） | 远船桅杆三点 | 真港口 Logo |
| 大桥 | 几乎不放主件，留雾带 | 桥塔尖两盏青灯伸进空 | 再叠一轮城 |
| 隧道 | **没有天空**：`00` 改成洞顶，灯成排 | 洞口远处一条横缝 | 在洞里画月亮 |
| 赛博荒原 | 一列轨道列车剪影从远空划过（细、长） | 数据点阵雨很淡，不是扫描线 | CRT 桶形、英文字 |
| 清晨原野 | 不放月，放启明星一颗琥珀 | 淡青横带 | 太阳升到刺眼 |
| 傍晚进城 | **落日**：扁椭圆，琥珀芯 + 品红晕（点阵，不是渐变） | 飞鸟 3 个三角剪影就够 | 写实火烧云照片 |

天气叠在主件上：雨是斜点，雪是大像素点，雾是近靛远淡的一层，大风只让小件（烟花屑、灯笼）水平错 1–2 格。不改主件形状。

## 图像 agent 一次交什么

每个「天色×主题」可以共用一张天色底，主件单独 PNG 透明底。

```
layers/00-sky/dusk.png
layers/00-sky/night.png
layers/00-sky/dawn.png
layers/00-sky/prop-moon.png
layers/00-sky/prop-sun-dusk.png
layers/00-sky/prop-signs-city.png
layers/00-sky/prop-fireworks.png
...
```

`manifest.md` 写清主件包围盒（x,y,w,h）和「不要挡路尖」。预览合成时先底后天色件，再 `01-far`。

## 验收

- 合成后从 y=0 往下数，连续「无饱和内容」行数 ≤ 320
- 路尖（消失点附近 40px）没有主件压住
- 主件量化后没有色卡外的色
