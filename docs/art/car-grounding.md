# 车接地

车像贴纸，不是机位错（修订 01 §6 先不动），是三件套都缺：格和点阵跟路不是一家、脚下没压印、尾灯没有落在路上。

车位锁死：宽 24%、底 80%、居中、只等比最近邻。本页只改「怎么贴到路上」，不改车在哪。

层：车身在 `06-cars`，压印 / 落光 / 残影在 `07-fx`，不要画进精灵文件。

## 1. 同一套格，同一档噪点

| | 现状（预览） | 要求 |
| --- | --- | --- |
| 车 | 大师图偏细，缩到约 170px 后点子比路「更整、更干净」 | 设计约 64×96，16–24 色，色卡内；上屏最近邻，宽高取偶数 |
| 路（远） | Bayer 1px，对比偏高 | cell 1px，对比弱 |
| 路（近，y>1000） | 仍是细 Bayer，比车还密 | **cell 3–4px**，对比强（修订 01 §7） |

近处路面要把点子放大到接近车身像素，车才不会像贴在一张细砂纸上。远路保持密、淡。不要给车加抗锯齿或软阴影来「融进去」。

跑车锚点 `paoche-rear.png` 四周有 6px 透明边，合成按整张缩放——可见车略小于 24%，已在容差内。重出车时把透明边收成 2px，仍不要让生成器重画已锁构图。

对向车比玩家车再简一档，同样 `p=2`，不要写实车灯体积。

## 2. 车底压印（辅助）

沿车底不透明轮廓向外 **2px** 硬边，颜色 = 路面基色的 60%（约 `#0b0517`）。

- 只在 `07-fx`
- 不羽化、不椭圆软影
- 压印可以压到虚线底下，但不要改虚线颜色

## 3. 尾灯落光（主手段）

路面基色大约只有 22/255，再压暗看不见。接地靠亮。

| 项 | 值 |
| --- | --- |
| 色 | `#e90cbe`，点阵递减，不用半透明粉 |
| 位置 | 两盏尾灯各自正下方，单侧宽约等于该尾灯（跑车约 45px） |
| 长度 | 从车底往下 20–30px |
| 点阵 | 4×4 → 2×4 → 断开 |
| 边界 | 不越过车道虚线，不画到邻道 |

复测：车底 +32px 那一行，车正下方亮度 − 同行李车外亮度 **≥ +12**。

## 4. 残影流光

落光是贴地的一块；残影是往消失点收的两条短带，让车在「开」。

| 项 | 平时 | 氮加速 |
| --- | --- | --- |
| 条数 | 2（对尾灯） | 2，更长更密 |
| 走向 | 从尾灯中心指向消失点 `(376, 700)` | 同 |
| 长度 | 车高的 0.6–0.9 倍 | 车高的 1.2–1.6 倍 |
| 宽 | 近 6px → 远 2px | 近 8px → 远 2px |
| 画法 | 品红实心格 + 间隔空格，近密远疏 | 同上，空格更短 |
| 层 | `07-fx`，画在车底下、路和氮光带上头 | 同 |

禁止：运动模糊、半透明拖尾、改车身形状、在精灵上烤残影。氮光带（`05`）是路肩两条宽带，残影是车屁股两条细带，不要做成一种东西。

刹车以后可以只留落光、收掉残影。第一版预览按「在开」交。

## 5. 图像 agent 一次交什么

1. 车精灵：透明 PNG，正后，不画地面、不画残影、不写字
2. 可选 `07-fx/tail-glow-mask.png`：只有两盏灯的落点标记（品红点），方便对位
3. 不要交「已经合成在路上的车」当大师图

玩家五辆车都要能套同一套落光/残影规则；灯的左右间距按各车尾灯量，不要共用跑车的 45px。
