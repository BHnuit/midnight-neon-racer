# 像素格

两套表面共用 **边长**，不共用 **畸变**。

| | 赛道 | 菜单 CRT |
| --- | --- | --- |
| 画布 | 720×1280（9:16） | 同，或 TaiT 选定比例 |
| 基格 `p` | **2px**（短边 / 360） | TaiT：短边 / 384，720 宽时取整为 **2px** |
| 对齐 | 所有描边、虚线、HUD、精灵锚点落在偶数坐标 | 窗、字、光标、棋盘格同一 `p` |
| 畸变 | 无。平直像素 | 外圈 10% 桶形，内 80% 稳定 |
| 扫描线 | 不要 | 必须，且只能用色卡里的色 |

TaiT 原文把 `p` 写成 `short / 384`。本项目画布短边 720，384 除不尽，统一钉死 **2px**，避免菜单和赛道各用一套格子。

## 赛道怎么落到格上

- 消失点、路缘、虚线先按透视算浮点，**画的时候四舍五入到偶数**。
- 精灵缩放用最近邻，目标宽高取偶数。跑车预览契约仍是宽 24% / 底 80%，不要为了格去改车位。
- 点阵 cell：远 1×1、中 2×2、近 4×4（都是 `p` 的整数倍，远段 1px 是唯一例外，只用于地平线附近）。
- 禁止半格、旋转格、抗锯齿过渡像素。

## HUD 数字

局内数字（时速、分数、加分飘字）走位图字，不要系统字体。

| 项 | 值 |
| --- | --- |
| 字模 | 5×7 或 6×8 格 |
| 上屏 | 每格 2px → 10×14 或 12×16 |
| 色 | 路程青、技巧琥珀、碾压品红 |
| 层 | `08-hud`，单独 PNG / 字表，不烧进路或城 |

菜单里的字跟 TaiT：5×7 / 6×8 / 7×9，和窗框同一 `p`。

## 和修订 01 的关系

透视验收脚本按像素读，不读格。格是画的时候的约束；消失点容差仍是 ±20px，不要为了贴格把路挪出容差。
