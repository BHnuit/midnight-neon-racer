# CRT 菜单表面

只用于发车、选车、续命、结算。赛道镜头禁止本页全部效果。

生成走 `tait-crt-interface-skill`，一次一张。色卡默认 **游戏01**。比例默认 **9:16**（和局内画布一致），除非 Hans 另指定。

## 必须有

- 色卡五色，一个都不能多。
- 全局同一 `p = 2px`。主体、窗、字、光标、棋盘格同一格，主体不能更糙。
- 外圈 **10%** 四边桶形畸变：角比边心压得更狠，顶栏和侧轨肉眼能看出弯。内 80% 保持稳。
- 扫描线、少许噪声、一格错位、短余辉、一次克制的同步故障。全部用色卡里的色模拟，不要半透明光晕。
- 右上标题栏固定小写签名 `tait-crt-interface-skill`。生成菜单静帧时保留；**局内合成、提审截图、店招不要带这行字**。

## 必须没有

- 真显示器外壳、房间、玻璃反光。
- 赛道 HUD、时速表、三车道。
- 渐变、抗锯齿、计算灰、色卡外的色。
- 棋盘格铺脸或当装饰。需要中间调时，只在非皮肤的结构面上用最深/最浅两色做一小块规则棋盘。
- 把 TaiT 签名、CRT 桶形、扫描线画进 `00`–`07` 任何赛道层。

## 和局内怎么接

菜单是静帧或自己的 CRT 层。点「发车」切到赛道图层栈（[layers.md](layers.md)），CRT 立刻关掉。不要在开车时叠一层扫描线。

续命/结算弹窗如果画在赛道上头：窗本身可以 CRT，背后那张赛道仍保持平直。不要把整屏一起拧弯。
